## Regeneration examples

1. "Make the about section shorter and clearer."
2. "Rewrite this headline in a confident tone."
3. "Use a concise call to action."
4. "Explain the services with less technical vocabulary."
5. "Make the description suitable for a general audience."

In deterministic demo mode, regeneration replaces the selected section's description with the requested text. It does not semantically understand or invent new content. Live mode sends a structured request to the configured provider and still limits changes to the selected component.
